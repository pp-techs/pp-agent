The agent can now create a scheduled task when you ask for something recurring ("every Friday at 16:00, summarize Reports"), and send you a message on Telegram, for example when a task has finished. Both ask first. They appear as "Schedule tasks" and "Message you on Telegram" in Settings › Tools and in an agent's tool list. A scheduled task can message you only when "Message you on Telegram" is set to Allow in Settings › Tools, and it cannot create tasks. The agent can also see which conversations are saved, read the end of one, and see which chats it can send to ("See other conversations"); it always knows the date and which conversation it is in.

Schedules now has its own navigation item beside Settings in the sidebar footer, opening a dedicated management page in the main panel. Workspace sessions use the full sidebar content area again, with no inline schedules or fixed height split. The Workspace management icon matches the muted group label color.

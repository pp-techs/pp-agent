# Connector logos

Brand logos shown on the Connectors cards, taken unmodified from [theSVG](https://thesvg.org)
(`https://thesvg.org/icons/<slug>/default.svg`; the Stripe file is its `stripe-badge`, the Context7
card uses `upstash`).
The library is MIT-licensed; each logo remains the trademark of its owner and is used here only to
identify the service the card connects to. They are bundled because the renderer's CSP
(`img-src 'self' data: blob:`) blocks remote images.

`pp-hub.svg` is PP Hub's own brand mark, copied from `apps/web/public/brand-mark.svg` of the pp-hub
repository; no third-party library is involved.

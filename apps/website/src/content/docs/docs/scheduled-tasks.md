---
title: Scheduled tasks
description: Ask PP Agent to repeat a job daily, weekly, or at a time you choose.
---

You can give PP Agent a recurring job, such as a Monday morning summary. Every run is saved so you can check it.

## Create a scheduled task

1. Open **Scheduled tasks**.
2. Write the job as if you were messaging a colleague. Name the files or folder it should use.
3. Choose the assistant and the time.
4. Save it, then run it once to check the result.

Example:

```text
Every Monday at 08:00, read the sales table in the workspace,
summarize the week-over-week change, and save a one-page brief
in reports/weekly/. Do not change the source file.
```

## Run with the window closed

Turn on **Settings › Background** so PP Agent keeps working after you close the app. Without it, scheduled tasks only run while the app is open.

## Tasks that need approval

When a task runs by itself, nobody is there to approve. Anything that needs approval is skipped and recorded in the result.

If you want a scheduled task to save a report, ask IT to allow the right tool for that task.

## Check results

Each run is a conversation. Open it to see what PP Agent did, what was skipped, and which files were created.

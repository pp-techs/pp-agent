---

PP Agent runs on your computer. There is no PP Agent account, and no PP Techs service receives your conversations.

## Where your data lives

- Conversations, documents, and settings stay on your computer.
- Sign-in details and connection codes are encrypted.
- There is no cloud sync.

## What gets sent?

Only what is needed for an answer:

| Destination          | Information sent                                  |
| -------------------- | ------------------------------------------------- |
| AI service           | The content needed to answer                      |
| Search tool          | Your search words                                 |
| Company software     | The lookup or change you approved                 |
| Voice service        | Audio, if you choose a service instead of on-device |
| Telegram or Zalo     | Messages in the paired chat                       |

## PP Agent does not change things on its own

- Looking and reading: no question.
- Saving files, changing data, using your computer: asks first.
- You can set permissions for each tool.

See [Permissions and approvals](/docs/tools-and-approvals/).

## Remote access

Remote access on the same Wi-Fi is not encrypted and is off by default. Turn it on only on a network you trust.

## Things to know

- The AI service you choose handles data under its own terms.
- Connected company software runs with your account’s permissions.
- Files you export are ordinary files; store them appropriately.
- “Always allow” means exactly that: the tool will not ask again.

## Report a security issue

Send it privately using
[SECURITY.md](https://github.com/pp-techs/pp-agent/blob/main/SECURITY.md). Do not open a public issue for a security problem.

---
title: Install PP Agent
description: Download and install PP Agent on a Mac, Windows PC, or Linux computer, and know what to expect the first time you open it.
---

PP Agent is a desktop app for Mac, Windows, and Linux. Download the installer from the
[latest release](https://github.com/pp-techs/pp-agent/releases/latest).

## Choose the right file

| Your computer              | File to download                                |
| -------------------------- | ----------------------------------------------- |
| Mac with Apple chip (M1+)  | `pp-agent-<version>-mac-arm64.dmg`              |
| Mac with Intel chip        | `pp-agent-<version>-mac-x64.dmg`                |
| Windows                    | `pp-agent-<version>-win-x64.exe`                |
| Linux                      | `pp-agent-<version>-linux-x86_64.AppImage` or `…-amd64.deb` |

Not sure which Mac you have? Open **Apple menu › About This Mac**. On Windows, check **Settings › System › About**.

## Install

1. Open the downloaded file.
2. On a Mac, drag **PP Agent** into **Applications**. On Windows and Linux, follow the installer.
3. Open PP Agent.
4. Continue with [First time here](/docs/first-run/).

You do not need a PP Agent account.

## If your computer warns you

Windows SmartScreen or macOS may warn you the first time because not every build is signed.

- **Windows:** choose **More info → Run anyway**.
- **macOS:** if the app is reported as damaged or will not open, ask your IT team. They can use the
  [build and packaging notes](https://github.com/pp-techs/pp-agent/blob/main/docs/architecture/build-and-packaging.md).

## Updates

PP Agent checks for a new version when it starts. You can also use **Settings › General › Updates**.

## Uninstall

Remove the app like any other app. Your conversations and documents stay on the computer; see
[Data on your computer](/docs/data-storage/) to back them up or delete them.

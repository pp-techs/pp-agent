## Common things people do

- **Summarize or compare documents** — attach the files and ask in plain language.
- **Prepare a report** — ask PP Agent to read the sources, pull the points together, and create a Word or PowerPoint file.
- **Look things up in company software** — once IT has connected your CRM, help desk, or internal tools.
- **Hand over a long job** — use `/goal` and PP Agent keeps working until it is done.
- **Research with sources** — use `/research` to get a report with links you can check.

## If you manage a team

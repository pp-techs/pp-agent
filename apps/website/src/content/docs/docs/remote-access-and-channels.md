---
title: Remote access and chat channels
description: Use PP Agent from your phone or another computer, and talk to it through Telegram or Zalo.
---

PP Agent does not need a cloud account. You can still use it from a phone on the same Wi-Fi, or through Telegram and Zalo.

## Use it on your phone in the same Wi-Fi

1. Open **Settings › Remote access** on the computer.
2. Turn remote access on.
3. Scan the QR code with your phone.
4. Chat, send photos, and approve requests from the phone.

:::caution[Trusted networks only]
This connection is not encrypted. Use it on your company or home Wi-Fi. Settings that let PP Agent run programs without asking stay on the computer and cannot be changed from the phone.
:::

This works inside your local network only, not from the internet.

## Work on another computer

In **Settings › Remote access**, choose **Work on another computer** to open that computer’s PP Agent in its own window. Useful when your main machine runs the agent and you are on a laptop.

## Telegram

1. Open **Settings › Chat channels › Telegram**.
2. Paste the bot code from @BotFather.
3. Turn Telegram on and choose **Pair**.
4. Send the pairing code to the bot.

Only the paired account gets replies. When PP Agent needs approval, the question appears in the chat.

## Zalo

**Settings › Chat channels** also supports Zalo with the same steps.

## Keep it running

Turn on **Settings › Background** so PP Agent keeps replying after you close the window. Without it, the app must be open.

title: First time here

---

PP Agent needs an AI service to answer. Your IT team will usually set this up; if not, you can do it yourself in a few steps.

## 1. Connect an AI service

Open **Settings › Models**. Choose the service your company uses, or sign in to Anthropic, OpenAI, Google, or another provider.

If your company gives you an account, use that one. Do not share connection details with other people.

## 2. Pick an assistant

An assistant already knows the instructions, documents, and folder for a kind of work.

1. Open **Settings › Agents**.
2. Choose an existing assistant, or create one if you manage the setup.
3. Select it from the top bar.

## 3. Ask your first question

Type as you would message a colleague. You can:

- drag a file into the message box;
- press **Cmd+J** (**Ctrl+J** on Windows and Linux) to open files and a browser beside the chat;
- type `/` to see commands such as `/goal`, `/research`, or `/new`.

## A good first task

Start with something that only reads, so you can see the flow:

```text
Read the attached Q3 report and list the three biggest changes from Q2,
with the page each number comes from.
```

Then ask PP Agent to create a Word file. You will see the approval step before it is saved.

---
title: Chat and documents
description: Attach documents, photos, and spreadsheets, check where answers come from, and ask PP Agent to create Office files.
---

You can attach a document right in the message box. PP Agent reads it, answers your question, and shows where the information came from.

## Common file types

PDF, Word, Excel, PowerPoint, photos, text files, and data tables. You can also paste an image into the message box.

## Asking a good question

- Say what you need: a summary, a comparison, a number, or a written report.
- Ask for a page or section reference so the answer is easy to check.
- If you attach several files, say which one is the main source.
- For a long job, use `/goal` so PP Agent keeps going until it is done.

Example:

```text
Compare Q2 and Q3 revenue in this spreadsheet.
Tell me which regions went up and which went down,
and quote the matching rows.
```

## Previewing and creating Office files

- PP Agent can create and edit Word, Excel, and PowerPoint files in the workspace.
- You see the changes and approve them before anything is saved.
- You can open the file in the side panel to review it.

## Keep the original

PP Agent works inside the workspace folder. Keep a copy of important documents somewhere else so you can restore them if needed.

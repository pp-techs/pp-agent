# Constraints and known limitations

| Area          | Limitation                                                                                                                                                                                               | Evidence                                                                                                                                          |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Documents     | officeparser fails on XLSX files that use prefixed XML namespaces, as written by the .NET OpenXML SDK (sheets parse as empty). Files from Excel, LibreOffice, or openpyxl work.                          | Reproduced during development; officeparser 8.2.0 matches literal `<c`/`<row` tags. No workaround in `apps/desktop/src/agent/documents.ts`.       |
| MCP OAuth     | OAuth tokens of MCP servers are stored in plain `<user-data>/agent/mcp-auth.json`, not in the safeStorage vault.                                                                                         | `README.md` configuration table.                                                                                                                  |
| Gateways      | A gateway's models are available only once a key is saved for it; `list_models` returns configured providers only.                                                                                       | `apps/desktop/src/agent/providers.ts`                                                                                                             |
| Compaction    | `/compact` does nothing on short chats: Pi keeps the most recent 20,000 tokens (`compaction.keepRecentTokens` default), so only older messages can be summarized.                                        | Pi `dist/core/settings-defaults.js`; `compact()` in `apps/desktop/src/agent/index.ts` maps Pi's "nothing to compact" error to a friendly message. |
| macOS release | Local packaging signs with whatever identity the keychain offers (an Apple Development certificate during development); no Developer ID or notarization is configured, so other Macs will block the app. | `apps/desktop/electron-builder.yml` has no signing or notarization settings.                                                                      |
| Windows       | The NSIS build target exists but is untested.                                                                                                                                                            | `apps/desktop/electron-builder.yml` `win.target`                                                                                                  |
| Renderer      | No network access, strict Content-Security-Policy in packaged builds; all I/O through the preload bridge.                                                                                                | `README.md`                                                                                                                                       |
| Edits         | Settings that affect the session are deferred while a run is active.                                                                                                                                     | `README.md`                                                                                                                                       |

# Constraints and known limitations

| Area            | Limitation                                                                                                                                                                                                                                                                                                                                                                                        | Evidence                                                                                                            |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Documents       | `read_document` (officeparser) cannot read XLSX files with prefixed XML namespaces (as written by the .NET OpenXML SDK); the agent is told to use `office_read` (OfficeCLI) for Word, Excel, and PowerPoint.                                                                                                                                                                                      | `packages/agent-core/src/tools.ts` system prompt.                                                                   |
| macOS release   | Developer ID signing and notarization apply only once the maintainers add the secrets (untested with real certificates); otherwise builds are ad-hoc signed and other Macs block them.                                                                                                                                                                                                            | `electron-builder.yml` `mac`; `release.yml` Make installers; `docs/code-standard/release-process.md` (Code signing) |
| Windows         | The NSIS installer is built in CI (build only), never run here. Signing is optional (`WIN_CSC_LINK` secret); otherwise it is unsigned and SmartScreen warns.                                                                                                                                                                                                                                      | `apps/desktop/electron-builder.yml` `win.target`; `.github/workflows/ci.yml` `build-windows`                        |
| Renderer        | No network access, strict Content-Security-Policy in packaged builds; all I/O through the preload bridge.                                                                                                                                                                                                                                                                                         | `README.md`                                                                                                         |
| Edits           | Settings that affect the session are deferred while a run is active.                                                                                                                                                                                                                                                                                                                              | `README.md`                                                                                                         |
| Local only      | The daemon listens only on a local socket (Unix socket or Windows named pipe, same user, token required). There is no remote UI and no network listener; reaching the agent from elsewhere means Telegram.                                                                                                                                                                                        | `apps/daemon/src/server.ts`, `apps/daemon/src/paths.ts`                                                             |
| Background      | Scheduled tasks and the Telegram bot run only while the daemon runs: with the login service installed, from sign-in on; without it, from when the app starts the daemon until the app quits (the tray option keeps the app, and so the daemon, running with the window closed).                                                                                                                   | `apps/desktop/src/main/daemon-client.ts` (`dispose`), `apps/daemon/src/service/`                                    |
| Linux service   | The service is a systemd **user** unit. It needs a user session bus (not available in a plain container or an SSH session without a login), and unless `loginctl enable-linger` is on it stops at logout and starts again only after the next login. Other init systems are not supported.                                                                                                        | `apps/daemon/src/service/systemd.ts`                                                                                |
| Windows service | A scheduled task that starts at logon with limited rights; nothing restarts it if the daemon exits. launchd (macOS) and systemd restart a stopped daemon.                                                                                                                                                                                                                                         | `apps/daemon/src/service/windows-task.ts`, `launchd.ts`, `systemd.ts`                                               |
| Vault key       | Without `PP_AGENT_MASTER_KEY` or a usable OS keyring (typical on headless Linux), the master key is the file `vault.key` beside `vault.json`: anyone who can read the data folder can decrypt the vault.                                                                                                                                                                                          | `apps/daemon/src/vault/index.ts`                                                                                    |
| Telegram        | One paired person, private chats only. The bot understands text, photos, documents and voice or audio (transcribed with the voice input provider; each download up to 20 MiB); any other message without text (stickers, video, locations) gets an "unsupported" reply. It polls the Bot API, so it needs outbound internet access, and Telegram refuses a bot token used by two pollers at once. | `packages/agent-core/src/channels/telegram/channel.ts`, `api.ts`                                                    |
| Chat approvals  | Tools that ask for approval are asked in the Telegram chat; unanswered requests are denied after 10 minutes. A scheduled task still skips actions that need approval.                                                                                                                                                                                                                             | `packages/agent-core/src/channels/telegram/approvals.ts`, [Scheduled tasks](use-case-scheduled-tasks.md)            |

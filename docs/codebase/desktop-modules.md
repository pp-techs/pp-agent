# Desktop modules

## Main process — `apps/desktop/src/main/`

| File        | Responsibility                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `index.ts`  | App lifecycle and window; forks the agent process and sends it `init` with `AgentPaths` (default workspace `Documents/PP Agent`, `userData/settings.json`); maps agent command ids to pending promises; forwards agent events to the renderer; restarts the agent process 1 s after an unexpected exit; registers every `ipcMain.handle(IPC.*)`; opens only http(s) URLs externally; blocks in-window navigation. |
| `vault.ts`  | The vault: `credentials.json` with each provider's `StoredCredential` encrypted by `safeStorage`. `handleVaultRequest` serves `read`/`list`/`write`/`delete` for the agent process.                                                                                                                                                                                                                               |
| `files.ts`  | Native dialogs and shell helpers: `pickFiles` (attachments), `pickSkill`, `pickFolder`, `openAgentFile`, `saveAgentFile`, `openFolder`, `isInside` path check.                                                                                                                                                                                                                                                    |
| `legacy.ts` | `migrateLegacyProvider`: converts the single-gateway settings of earlier versions before the agent process starts.                                                                                                                                                                                                                                                                                                |

## Agent process — `apps/desktop/src/agent/`

| File                | Responsibility                                                                                                                                                                                                                                                                                                                                              |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `index.ts`          | `AgentHost`: `handle(command)` switch over every agent command; session lifecycle (new/open/rename/delete/compact conversation), Pi event → `ChatMessage` mapping, approval gate, `changed(scopes, apply)` which emits `settings_changed` and defers session reloads until a run settles. Receives `init`/`command`/`vault_result` on `process.parentPort`. |
| `ipc.ts`            | `send`, `emit(AgentEvent)`, `errorMessage` — the only path to the main process.                                                                                                                                                                                                                                                                             |
| `settings-store.ts` | `SettingsStore`: reads/writes `settings.json` (`SettingsFile`: app settings, gateways, agents, workspaces). Files from before workspaces turn each folder an agent used into a workspace on load.                                                                                                                                                           |
| `credentials.ts`    | `VaultCredentialStore`: Pi `CredentialStore` backed by the vault in the main process, with a local cache.                                                                                                                                                                                                                                                   |
| `providers.ts`      | Providers and gateways: URL normalization, gateway ids, registering gateways with Pi (`syncGateways`), fetching gateway models, model summaries/lookup, `listProviders`, sign-in `authInteraction`.                                                                                                                                                         |
| `auth-prompts.ts`   | `AuthPrompts`: pending questions of a sign-in flow, emitted as `auth_prompt` and answered by `respond_auth_prompt`.                                                                                                                                                                                                                                         |
| `agents.ts`         | Agent profiles: `DEFAULT_AGENT`, validation, ids/unique names, export/import file format, the agent's system-prompt section, tool options for the agent editor.                                                                                                                                                                                             |
| `workspaces.ts`     | Workspace profiles: `DEFAULT_WORKSPACE`, validation, ids/unique names, folder preparation (`prepareFolder`), matching a session's `cwd` to its workspace (`workspaceForCwd`), the workspace's system-prompt section, migration from agent folders.                                                                                                          |
| `tools.ts`          | `SYSTEM_PROMPT`, built-in `AGENT_TOOLS` (incl. example `currentDateTimeTool`, shell tool `bash`/`powershell`), tool tier classification, tool policy resolution (`toolRule`), active tool selection per agent, MCP tool-name parsing, `describeToolCall` for approval cards.                                                                                |
| `documents.ts`      | `read_document` tool: extracts text from office/PDF formats via officeparser inside the workspace.                                                                                                                                                                                                                                                          |
| `attachments.ts`    | `buildPrompt`: turns attachments into image content or attached-file references; `splitAttachedFiles` for transcript display.                                                                                                                                                                                                                               |
| `transcript.ts`     | `Transcript`: the renderer-facing `ChatMessage` list built from Pi session messages and streaming events.                                                                                                                                                                                                                                                   |
| `skills.ts`         | `SkillLibrary`: list/read/save/delete/enable skills, import from folder or `.zip`/`.skill` archive (with expansion limit), `validateSkillName`.                                                                                                                                                                                                             |
| `mcp.ts`            | MCP servers: `McpConfigFile` (`mcp.json`), status parsing, `buildOverview`, `McpRegistrations` and `McpCommands` (save/delete/reconnect/sign in/out).                                                                                                                                                                                                       |

> Assumption: detailed responsibilities above are taken from file header comments and exported symbols; see each file for behavior specifics.
